# Archive

## metal/

The first version of this project targeted metal artists and discographies. It was dropped after research showed the corpus was patchy: six headline bands had no page in the `music-wiki` snapshot, no free metal dataset was found, and no permission to reuse Encyclopaedia Metallum was found. These files are a snapshot of the docs at that point (README, CONTEXT, DOMAIN and the technical docs), kept as a record. They are not current. The current docs are in the parent folder, and the reasons for the change are in decisions 1 and 2 of [../DECISIONS.md](../DECISIONS.md).
